# Manual Website Testing Project

## Project Overview

This project demonstrates real-time manual testing performed on a website. The testing included test case preparation, test execution, functional validation, UI validation, and defect identification.

## Testing Activities

* Test Scenario Preparation
* Test Case Design
* Functional Testing
* UI Testing
* Form Validation
* Navigation Testing
* Test Execution
* Defect Identification
* Expected vs Actual Result Validation
